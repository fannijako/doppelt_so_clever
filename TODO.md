# Doppelt so clever — Missing Rules / Bugs

## Grey Question Mark — Filter Already-Crossed Boxes
`GreyQuestionMarkAction` offers all 24 color/value combinations regardless of whether those boxes are already crossed. The grey question mark should only allow choosing uncrossed boxes.

## Score Sheet Display During Interactive Play
During interactive mode, there is no visual rendering of the current state of the score sheet. Players only see log output. The score sheet should be displayed to support decision-making.
